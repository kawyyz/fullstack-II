# Sistema de Gestión de Museos (DSY1104, Evaluación Parcial 1)

Este proyecto consiste en el desarrollo del frontend para un sistema de administración centralizada de museos, clientes, reservas y pagos. El sistema ha sido diseñado para interactuar con una arquitectura de backend basada en microservicios, permitiendo una gestión eficiente de las visitas culturales.

## 🚀 Descripción del Sistema

La plataforma permite a los usuarios finales navegar por un catálogo de museos, realizar reservas de visitas y gestionar los pagos correspondientes para la obtención de tickets de entrada. Todo el flujo está optimizado para proporcionar una experiencia de usuario fluida y profesional.

## 📁 Estructura del Proyecto

`
Museo/
├── index.html         # Panel principal (Dashboard)
├── login.html         # Gestión de acceso y autenticación
├── museos.html        # Catálogo de museos disponibles
├── reservas.html      # Formulario de reserva de visitas
├── pagos.html         # Procesamiento de pagos
├── tickets.html       # Visualización y descarga de entradas
├── clientes.html      # Gestión de perfil de usuario
├── css/
│   └── style.css      # Estilos globales y diseño responsivo
└── js/
    └── main.js        # Lógica de interacción del frontend
`

## 🛠️ Flujo de Navegación

El sistema sigue un flujo lógico de negocio:
**Acceso** $\rightarrow$ **Inicio** $\rightarrow$ **Catálogo de Museos** $\rightarrow$ **Reserva de Visita** $\rightarrow$ **Pago** $\rightarrow$ **Emisión de Ticket**.
